# Marketing Campaign Analytics MCP server

The Marketing Campaign Analytics (formerly known as Mix Modeler) MCP server lets Adobe Coworker interact with your components and data in Marketing Campaign Analytics. Once connected, the Marketing Campaign Analytics MCP server provides unified marketing measurement combining marketing mix modeling with multitouch attribution.


## Endpoint

```
https://mca-mcp.adobe.io/mcp
```

## Capabilities

* Channel performance and contribution
* ROI and CPA 
* Baseline (non-marketing) contribution
* Response/saturation curves.
* Cross-channel synergy.
* Marketing scenario planning with AI-powered budget optimization.

See the [tool reference](reference.md) for a complete list of available tools, how and when to use the tools, the input for each of the tools, and more. 

## Get started

Currently, the Marketing Campaign Analytics MCP server is only available through Adobe CX Enterprise Coworker.
